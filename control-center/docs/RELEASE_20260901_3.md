# OpenStick Control Center 2026.09.01.3

## 目标

在不使用蜂窝数据、不读取或写入 eSIM 的前提下，建立可验证的 USB eSIM 下载出口，并修复 Windows ICS 无 DHCP 响应时的 USB 上行配置。

## 变更

- USB 上行改用固定地址 `192.168.137.28/24`，网关为 `192.168.137.1`，避免 DHCP 超时后回滚。
- 新增受限 Windows USB 代理：`192.168.137.1:17897 -> 127.0.0.1:7897`。
- eSIM 下载仅在 `usb0` 代理可达，或其他非蜂窝出口可用时放行。
- lpac 自动继承已验证的 USB HTTP/HTTPS 代理。
- Uplink Manager 通过真实 HTTPS 请求验证代理出口。
- 蜂窝出口仍会被 eSIM 下载保护逻辑拒绝。

## 验证

- 本地单元与契约测试：24/24 通过。
- 设备 HTTPS：`https://connect.rom.miui.com/generate_204` 成功。
- `/api/uplink`：`active=usb`、`internet=true`、`connectivity_check=passed`。
- `/api/esim-network`：`interface=usb0`、`cellular=false`、`safe_for_download=true`、`transport=usb_proxy`。
- 设备 7/7 必要服务正常。
- 部署后后端和 Uplink Manager SHA-256 与本地一致。
